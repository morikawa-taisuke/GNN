# データ仕様書 (Data Format Specification)

LLM（RAG）や新しくプロジェクトに参加するメンバー向けの、データ構造および各種パラメータの設定基準のまとめです。

## 1. 音声データの基本仕様
- **サンプリングレート (SR)**: `16,000 Hz` (`fs=16000`)
- **チャンネル数**: 基本はモノラル（`1ch`）入力ですが、`make_dataset.py` には複数チャンネルの空間的な遅延を模倣する前処理スクリプトが含まれています。
- **クリッピング/音声長**: `make_dataset.py` などの中で、最大 `128,000` サンプル（約8秒）に制限されている箇所が多く見られます。それより短いものは学習時にゼロパディングされます。

## 2. STFT (短時間フーリエ変換) パラメータ
`main_Speq.py` などの周波数領域モデルで主に使用されるデフォルトの設計パラメータは以下の通りです。
- **`n_fft`**: 512
- **`hop_length`**: 256 (スクリプトによっては 128 も使用)
- **`win_length`**: 512
- **窓関数**: `Hann Window`

## 3. テンソルの Shape (形状) の仕様
モデルや Dataset が返すテンソルの基本的な次元構成です。RAG がデバッグを行う際にこの Shape 情報を基準とします。

### 時間領域モデル (`main_Wave.py` 系)
- 入力波形 (`mix_data`): `[BatchSize, Channels=1, TimeStep]`
- 正解波形 (`target_data`): `[BatchSize, Channels=1, TimeStep]`

### 周波数領域モデル (`main_Speq.py` 系)
`DataLoader` から出力されるのは時間波形ですが、スクリプト内で `torchaudio.stft` 等を用いて複素スペクトログラムに変換されます。
- 入力振幅スペクトログラム (`mix_magnitude`): `[BatchSize, 1, FreqBins=257, TimeFrames]`
- `SpeqGNN`等のネットワークは、この周波数ビン（257）を少数の特徴ノード（例: `num_node=32`）に集約してグラフを構築し、Message Passing を行います。

## 4. データ記録形式
基本的には `CsvDataset.py` などを利用して、**CSVファイル上に記述された絶対パス**から `.wav` をリアルタイムで読み込む構成になっています。
しかし一部の機能では、入力と正解信号を高速に読み込ませるために、NumPyの `.npz` ファイルにパックされることがあります（その場合のキーは `mix` と `target` で、中身は `float32` 型の配列です）。
